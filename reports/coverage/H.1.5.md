# H.1.5 电子测量与仪器：覆盖表

**状态（2026-11-23）：已写完，17 课，等用户验收。** 依据 `../cs-math-skill-tree/data/outlines/H.1.5.json`（主来源北京工业大学《现代电子测量技术及仪器》课程教学大纲 2020 版第 1–9 章；阻抗测量一章取广州华商学院《电子测量技术》教学大纲第七章）、`data/curation/learning-paths/H.1.5.json`（沈阳工业大学《电子测量技术基础》MOOC、Witte《Electronic Test Instruments》第 2 版、NIST TN 1297、NI 仪器总线白皮书）和原技能树综合练习 8 小题。数值核对脚本 `tests/content/H.1.5.verify.py`。

前置：必须前置 H.1.1（电压、电流、欧姆定律、戴维南等效、时间常数、增益、方均根、低通滤波器、量化、ADC、DAC、混叠可直接用），往下还有 M.3.1（方差、最小二乘）和 M.1.x。推荐前置 H.1.3 的频谱、分贝、波特图和 M.6.1 的正态分布在用到时简短重述。

## 课的安排

| 课 | 章 | 内容 |
|---|---|---|
| `measurement-basics` | 测量误差与不确定度 | 测量和计量、单位和溯源、电子测量的特点和仪器分类；绝对误差、相对误差、引用误差和仪表的准确度等级 |
| `random-systematic` | 测量误差与不确定度 | 平均值、实验标准差、正态分布、平均值的标准差；粗大误差（3σ 准则、格拉布斯准则）；系统误差的来源、发现和修正 |
| `uncertainty` | 测量误差与不确定度 | A 类和 B 类评定、合成标准不确定度、扩展不确定度和测量结果的写法；误差的传递（综合练习 1） |
| `data-processing` | 测量误差与不确定度 | 有效数字和数字修约（四舍六入五凑偶）、等精度测量结果的处理步骤、最小二乘直线拟合 |
| `dmm-loading` | 万用表与电压电流测量 | 数字万用表的组成、位数和分辨力、准确度指标；电压表的负载效应、电流表串联和分流电阻、两线和四线测电阻（综合练习 2） |
| `dvm-adc` | 万用表与电压电流测量 | 电压测量概述；逐次逼近和双积分模-数转换，双积分对工频干扰的抑制 |
| `ac-voltage` | 万用表与电压电流测量 | 峰值、平均值、方均根值，波形因数和波峰因数；均值表、峰值表按正弦定度带来的波形误差，真有效值表；dBm、dBV 和以电压测量为基础的其他测量 |
| `scope-basics` | 示波器与触发 | 示波器概述、垂直和水平通道、扫描和触发（电平、斜率、方式）、模拟示波器、X–Y 方式和李萨如图形测频率和相位 |
| `digital-scope` | 示波器与触发 | 数字示波器的采样率和存储深度、混叠、实时采样和等效时间采样（取样示波器）、带宽和上升时间、10× 探头和探头补偿（综合练习 3） |
| `signal-sources` | 信号发生器 | 信号源的电路模型和 50 Ω 输出、按 50 Ω 负载标定的幅度、函数发生器、脉冲发生器的参数、射频信号源（综合练习 4） |
| `frequency-synthesis` | 信号发生器 | 频率合成：锁相环频率合成器、直接数字频率合成（DDS）和任意波形发生器 |
| `frequency-counter` | 信号发生器 | 时间的原始基准和标准（铯原子秒）、通用电子计数器测频和测周期、±1 误差和中界频率、时基误差 |
| `logic-analyzer` | 逻辑分析仪 | 数据域测试的特点、逻辑笔、逻辑分析仪的定时分析和状态分析、毛刺捕获、触发字和触发序列（综合练习 5） |
| `spectrum-analyzer` | 频谱分析仪 | 信号的频域分析、滤波器组式、FFT 式和扫频外差式频谱仪、分辨率带宽、dBm 和热噪声底（综合练习 6） |
| `frequency-response` | 频谱分析仪 | 线性系统频率特性的测量：逐点法、扫频法、网络分析仪 |
| `impedance` | 阻抗与LCR测量 | 伏安法和两种接法的误差、直流电桥和交流电桥、谐振法（Q 表）、LCR 表、ESR 和损耗因数、四端测量（综合练习 7） |
| `ate-bus` | 自动测试与仪器总线 | 自动测试系统的组成和发展、虚拟仪器、系统集成：GPIB、USBTMC、LXI、PXI 和 SCPI、VISA（综合练习 8） |
