# 启发式评估：改版前的界面（2026-11-03）

> `after/` 的截图里是 2026-11-04 换下的旧导师，已经删掉；表里的 `after/…` 文件名留作记录（截图在作者本地的 git 历史里）。现在的界面见 README 的预览图（`docs/images/`）。

用户反馈（2026-11-03）：界面太丑、不像多邻国、没有音效、不太符合 HCI 与 UX；总览图缩放不跟着指针。这份报告按公认的标准把问题列清楚，作为改版的依据，改版后用同一张表复查。

## 方法

- **标准**：Nielsen 的 10 条可用性启发式原则（Nielsen 1994，NN/g 现行版本），每条问题标注违反哪一条。
- **严重度**：Nielsen 的 0–4 分级（*Severity Ratings for Usability Problems*，1995）：0 不算问题；1 外观问题，有空再修；2 小问题，低优先级；3 大问题，高优先级；4 灾难，发布前必须修。综合考虑出现频率、影响程度、是否反复遇到。
- **材料**：系统 Edge、1366×860 桌面和 390×844 手机的真实截图（`before/`），以及代码里的交互逻辑。
- **局限**：只有一名评估者（主代理）。Nielsen 的数据是单人大约只能找出 35% 的问题，建议 3–5 人；所以这份清单不全，改版后还需要真人试玩。

## 改版对策（对应上面的编号）

| 对策 | 解决 | 做法 |
|---|---|---|
| 开场与新手引导 | 1 | 第一次打开播一段可跳过的开场：像素背景、两位导师角色登场，打字机对白带音效，3–4 句讲清“一次一小课、答错不扣分、每章告诉你去哪深入”，最后直接进入选路线。“我的”里可以重看 |
| 选路线：推荐 + 自定目标 | 2 | 推荐的 4 条放在最前；下面“自己定目标”：按领域分组、可搜索的 183 个技能，选中后先预览自动生成的路线（几站、几站有互动课、约多少分钟），确认后出发 |
| 多邻国式路径 | 3、4 | 竖向蜿蜒的圆形关卡按钮，每个技能是一个“单元”色带；当前关卡上方弹出“开始”气泡写明章名和时长；角色小人站在当前关卡旁；说明文字收进“关于这条路线”折叠 |
| 课程反馈 | 5、6、7、8 | 粗进度条 + “第 3/7 题”；答对/答错从底部滑出整条反馈栏（绿/橙），配音效和角色反应（答对跳起来、答错捂脸）；交互题答错只标出错的地方，不把说明变红；课程区放大、加角色侧栏 |
| 结算庆祝 | 9 | 星星逐个弹出并配音、经验数字滚动、角色跳舞、彩带 |
| 用词 | 10、11、12 | 面向新手的词：“前置”→“要先学”，“支线”→“顺路推荐”，“关底”→“结业挑战”，不显示内部编号；技能页只留一个主按钮，其余收进次要区；“我已经会了”加确认 |
| 地图缩放 | 13、14 | 已修：滚轮/双指以指针为焦点，按钮以视口中心为焦点（`15a14675`，回归测试比较缩放前后指针下的位置）；初始缩放改到文字可读，再提供“看全部” |
| 声音 | 15 | 程序合成的 8-bit 音效（ZzFX，MIT），顶栏有静音开关，设置保存在存档里 |
| 视觉风格 | 16 | 像素奇幻“魔法学院”：Fusion Pixel 像素字体（OFL）用于标题和按钮，正文仍用易读字体；像素背景用本机 ComfyUI 生成；角色用方块像素小人（只用全年龄的动作）和作者提供的立绘（只用胸像裁切） |
