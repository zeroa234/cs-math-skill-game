第一个公开版本。和之前发过的 1.0.1 相比：

新内容
- 两位新导师：鲸鱼娘姐妹（鲸鱼姐姐、鲸鱼妹妹），角色设计 ZipZipPipe（CC BY-NC 4.0）。
- 背景音乐：25 首，4 种风格（像素 RPG、8-bit 芯片、中世纪奇幻、Lo-fi 学习），开场、营地、上课、结业挑战各放不同的曲子。在“我的”里开关、换风格、调音量，顶栏喇叭一键全关。
- 检查更新：App 每天自己看一次有没有新版本，有就在营地提示；“我的”页最下面可以手动检查。
- 实验室：课里每遇到一个新的实验（比如一步一步执行一段程序、当一回调度器），实验室就多一个，可以随时再玩。

修好的
- 地图上拖动以后，技能卡片有时点不开。
- 从技能页返回，回到你来的地方（地图、路线或营地）；地图保持原来的缩放和位置。
- “换一条远征”放到了营地和路线页上显眼的位置。
- 手机上顶栏的“我的”被挤出屏幕；课程顶部写成“第 N 章 · 章名”，和路线页一致；按钮叫“下一课”。
- 地图来回缩放会越来越偏向左上角。
- 手机上点地图里的技能：第一次点选中（亮出要先学的技能链），再点一次才打开；提示也改成“双指缩放、拖动移动”。
- 术语解释框在手机上不再被裁掉。

安卓：下载下面的 APK，第一次安装时允许“安装未知应用”。装过旧版的直接覆盖安装，进度不丢。
电脑：下载下面的 web.zip，解压后双击里面的 index.html，用浏览器玩，不用联网。
