## 推荐远征“算法”开放

- 第一条推荐远征开放：证明方法与离散结构 → 程序设计基础 → 数据结构 → 算法分析与设计，4 站都有互动课。
- 新的“证明方法与离散结构”（33 课）：命题和蕴含、归纳和强归纳、反证、良序原理、状态机和不变式、稳定匹配、递归数据和结构归纳、等价关系和偏序、递推式和主定理。
- 新的“算法分析与设计”（46 课）：渐近分析和倍增实验、递归树和主定理、分治（三次乘法、比较排序的下界、随机选择和快速排序、Strassen、FFT）、贪心（最小生成树和并查集、Huffman 编码、Horn 公式、集合覆盖）、动态规划和摊还分析、图的遍历、最短路、网络流与匹配、字符串匹配与索引。课里可以亲手当 Dijkstra、一条条找增广路把流送到最大。

## 学习与操作

- 手机上比屏幕宽的公式、表格和代码，被截断的一边会渐隐，提示可以左右滑。没有断点又比一行宽的行内公式会自动放到单独一行。
- 修正：程序设计基础“改动列表和字典”和数据科学导论有两道题在讲循环之前就用了 for 循环，已改写；写课的检查现在也会看题目里的程序。

安卓可以下载 APK 覆盖安装。Windows 可以下载安装版（`windows-x64-setup.exe`），双击安装后从开始菜单打开，进度保留；第一次运行时 SmartScreen 可能提示“未知发布者”，点“仍要运行”。也可以下载电脑版 ZIP，解压后双击 `index.html` 离线游玩。在线网页版需要联网。
