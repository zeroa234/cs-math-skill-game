## 界面字体可切换

- 针对部分屏幕上像素字体长时间阅读不便的问题，新增 **3 种字体模式**：
  - **像素字体（默认）**：全界面保持 Fusion Pixel 像素字体。
  - **像素标题 + 清晰正文**：标题、关卡等保留像素风格，课文、选项与代码改用系统清晰字体。
  - **清晰黑体（系统字体）**：全界面使用系统无衬线字体与清晰等宽代码字体。
- 可在 **我的 → 设置 → 界面字体** 中切换，也可以在**上课、结业挑战、复习**界面的顶栏点击 **字体** 按钮直接切换，无需退出当前课程；设置会自动保存进本地存档。

## 新增课程内容

- 上线 **人工智能远征** 的两站新课（按零基础与大纲覆盖标准编写，已在地图上开放）：**多元微分学**（29 课）与 **概率论**（16 课），数值与算例均经 SymPy / SciPy 独立核对。现在游戏里一共有 **42 个技能、906 课**、3924 道即时判题的练习与 435 道结业挑战题。

存档不受影响，覆盖安装后进度还在。安卓可以下载 APK 覆盖安装；Windows 可以下载安装版（`windows-x64-setup.exe`），双击安装后从开始菜单打开，进度保留；也可以下载电脑版 ZIP，解压后双击 `index.html` 离线游玩。在线网页版需要联网。
