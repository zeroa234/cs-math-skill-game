## 修正

- 极限与连续“夹逼定理与 sin x / x”：补上 sin x < x < tan x 成立的条件（0 < x < π/2），并说明为什么 0 左边也成立。
- Python与科学计算工具“批量处理文件”：给文件名加日期前缀的例子，改名前先检查新名字有没有被别的文件占用。原来的写法在 Linux 和 macOS 上会直接覆盖那个文件，在 Windows 上会报错。

安卓可以下载 APK 覆盖安装。Windows 可以下载安装版（`windows-x64-setup.exe`），双击安装后从开始菜单打开，进度保留；第一次运行时 SmartScreen 可能提示“未知发布者”，点“仍要运行”。也可以下载电脑版 ZIP，解压后双击 `index.html` 离线游玩。在线网页版需要联网。
