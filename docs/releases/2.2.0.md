- 这次重新开放三条推荐远征：**企业与桌面应用开发**（11 站、211 课）、**手机应用开发**（9 站、185 课）和**嵌入式开发**（20 站、447 课）。加上“我的远征：操作系统”以及之前已开放的“算法”“网络安全”“云与运维（DevOps）”“网站开发”，八条推荐远征里已有七条可以从头玩到点亮，仅剩“人工智能”还在重写。

## 题库与表述打磨

- 清理了各技能包课程正文与练习里残留的教材章节编号、高校课程代号与内部技能编号，所有外部延伸阅读统一收归章节页与技能页。

这 13 个新技能包的每一节知识点都对照技能树大纲做了覆盖检查，代码、电路仿真（ngspice）、数字逻辑（Icarus Verilog）、MIPS 汇编（SPIM）、C/POSIX 与数学算例均由对应验证脚本实测核对。存档不受影响，覆盖安装后进度还在。

安卓可以下载 APK 覆盖安装。Windows 可以下载安装版（`windows-x64-setup.exe`），双击安装后从开始菜单打开，进度保留；第一次运行时 SmartScreen 可能提示“未知发布者”，点“仍要运行”。也可以下载电脑版 ZIP，解压后双击 `index.html` 离线游玩。在线网页版需要联网。
