## 界面

- 两位导师换成了新的 Q 版像素小人，多了看讲解、想一想和欢呼的动作。
- 答题反馈更明显：答对时题卡弹一下，答案栏上落下一个绿色对勾印章并迸出像素火花；答错时题卡晃一下，落下红色叉。手机上看不到导师，这些反馈也照样有。
- 修复：课程完成页的彩带在点“下一课”后会继续落在下一课的题目上（手机上还可能停住不动）。现在离开完成页就会清掉。
- “我的”里的“减少动画”开关现在也会关掉界面上的动画，和系统的“减少动态效果”一样。

## 存档

这 5 个技能在 2.0.0 时有过一版旧课，这次是整个重写。读档时会清掉它们的旧进度（技能、课和复习卡），经验、连续天数、成就和其他技能的进度都保留。

安卓可以下载 APK 覆盖安装。Windows 可以下载安装版（`windows-x64-setup.exe`），双击安装后从开始菜单打开，进度保留；第一次运行时 SmartScreen 可能提示“未知发布者”，点“仍要运行”。也可以下载电脑版 ZIP，解压后双击 `index.html` 离线游玩。在线网页版需要联网。
